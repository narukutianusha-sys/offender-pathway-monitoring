# Offender Pathway Monitoring via Electronic Message Tracing Platform

## Project Overview
This mini project focuses on monitoring and tracing electronic message records to support criminal data management and tracking activities.

## Modules
1. Admin Module
   - Admin Login
   - Add Criminal Data
   - View and Delete Criminal Data
   - View and Activate Police

2. Police Module
   - Police Registration
   - Police Login
   - Track Criminal

## Technologies Used
- Java
- HTML5
- CSS3
- JavaScript
- JSP
- MySQL
- Apache Tomcat
